# ❤️ Heart Disease Analysis Dashboard

## 🎯 Project Overview
This project analyzes heart disease data using Power BI to identify risk factors, patient characteristics, and health trends.

---

## 🧹 Data Cleaning
- Removed duplicates
- Handled missing values
- Corrected data types
- Prepared healthcare data for analysis

---

## 📈 Dashboard Features
- Patient Demographics Analysis
- Heart Disease Risk Factors
- Cholesterol & Blood Pressure Analysis
- Age Group Analysis
- Health Trends Visualization

---

## 💡 Key Insights
- Older age groups show higher heart disease risk
- High cholesterol is strongly associated with heart disease
- Blood pressure and chest pain type affect diagnosis
- Certain patient groups require early monitoring

---

## 🎯 Recommendations
- Encourage regular health screening
- Focus on preventive care for high-risk groups
- Promote healthy lifestyle awareness

---

## 🛠️ Tools Used
- Power BI
- Excel
- DAX
- Power Query
